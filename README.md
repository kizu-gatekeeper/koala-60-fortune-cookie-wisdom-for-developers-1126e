A tiny program that cracks open one fortune cookie written for a software developer.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or to `/tmp/out/entry.txt` when that variable is not set.
